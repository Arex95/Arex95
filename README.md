### 📦 Featured Project: [@arex95/vue-core](https://www.npmjs.com/package/@arex95/vue-core)
[![npm version](https://img.shields.io/npm/v/@arex95/vue-core.svg?style=flat-square&color=00DC82)](https://www.npmjs.com/package/@arex95/vue-core)
[![npm downloads](https://img.shields.io/npm/dm/@arex95/vue-core.svg?style=flat-square&color=white)](https://www.npmjs.com/package/@arex95/vue-core)

A comprehensive core library designed to streamline Vue development without sacrificing flexibility.

- 🏗️ **RESTful Standard:** `RestStd` class for semantic API calls (e.g., `User.getOne()`).
- 🔌 **Fetching Agnostic:** Compatible with Axios, ofetch, or native Fetch API.
- 🔐 **Auth & Security:** Integrated JWT system and secure storage with encryption.
- 🚦 **Robustness:** Built-in retry logic (Exponential Backoff) and typed error handling.
- 🌐 **SSR/SSG Ready:** Native support for server-side rendering and cookie management.
